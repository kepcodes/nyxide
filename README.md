# NyxIDE

Простая IDE для разработки на Electron + Monaco Editor + xterm.js.

## Возможности

- 📝 Редактор кода на базе **Monaco** (движок VS Code)
- 📁 Файловый менеджер с деревом
- ⌨ Встроенный **терминал** (bash) внизу
- 🎨 **4 темы:** тёмная, светлая, высокий контраст, своя
- 🔤 Подсветка синтаксиса для 30+ языков
- 📑 Вкладки для открытых файлов
- 💾 Автосохранение при Ctrl+S
- 🖥 Своя шапка окна с меню (Файл, Правка, Вид, Окно, Справка)
- 📱 Адаптивность под любые разрешения

## Установка

### Требования

- Node.js 18+
- npm
- Linux / Windows / macOS

### Установка и запуск

```bash
git clone https://github.com/ТВОЙ_НИК/nyxide.git
